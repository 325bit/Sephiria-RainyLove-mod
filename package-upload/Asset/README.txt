音频文件说明（mod 的 Asset/ 目录）

随包附带（订阅后直接可用，开箱即听）：
  - rainylove.mp3   （最后存活时播放，RainyLove 源）
  - AIZO.mp3        （残血时播放，AIZO 源）

可选：用自备文件覆盖
  - rainylove.wav / AIZO.wav
  同名 .wav 的优先级高于附带的 .mp3，想做无损替换时直接放同名 wav 即可。
  wav 需要是 16-bit PCM；音量会在本地临时目录渲染一份缩放后的副本，原始文件不会被修改。

播放说明
  - 通过 Windows 系统 MCI 接口播放（不依赖游戏内音频系统）。
  - 同一时间只会有一首在响：新的一首开始前会先关闭上一首。
  - mp3 的音量由系统音频设备直接调节；wav 没有系统音量接口，所以改用本地渲染副本。
